01 · How it works

One app, every screen you listen on.

ZMyusic talks to YouTube Music with your own Google account, then draws the whole experience itself — the same library, queue and lyrics across Android, TV, desktop and iOS.

1

Sign in

Connect your Google account for personalised home, library and playlists — or use it signed out for a clean, account-free player.

2

Play anything

Search, browse and stream from YouTube Music, with Hi-Res lossless from a configured module source when you want it.

3

Make it yours

Animated artwork, synced lyrics, dynamic theming, per-network quality and offline downloads — all kept in sync by the app's own update checker.

Built with

  • Kotlin — Android phone, tablet, TV, Wear OS and the JVM desktop
  • Swift — iPhone and iPad
  • Go — the Listen Together party server

Runs where

  • Android 8.0+ on phones and tablets
  • Android TV (Leanback)
  • Wear OS 3+
  • Windows 10/11, Linux, macOS 13+
  • iPhone and iPad, iOS 17+

Bring your own

  • Spotify playlists and Liked Songs
  • Local music library
  • Pluggable module sources
  • Last.fm and ListenBrainz scrobbling

03 · Download

One release, every platform.

Every build comes from the same tagged release on GitHub, produced by CI. Signed APKs install straight over an older ZMyusic; the desktop builds are unsigned unless noted.

Looking for something else? Every asset, including ABI splits and checksums, is on the latest release page. To verify a download, on Windows run Get-FileHash .\ZMyusic-setup.exe, on Linux/macOS run shasum -a 256 <file>, and compare with the release's checksums.

04 · Install

A few minutes, a few taps.

Download the build for your device

Pick the installer from the section above. Android and Wear OS need “Install unknown apps” enabled for whichever app you download with.

Install it

Android and Windows run their own installers. macOS may warn the first time — right-click the app and choose Open, or run xattr -cr /Applications/ZMyusic.app.

Open and sign in

Use ZMyusic signed out, or sign in with Google for your personalised library. Spotify, Last.fm and Listen Together connect from Settings.

Keep it updated

ZMyusic checks GitHub Releases on launch and when it comes back to the foreground, and offers the newer build right inside the app.

To build from source

You need JDK 21 (Android also builds on 17), Android SDK 37, and the NDK/CMake toolchain for the native audio components.

./gradlew assembleDevDebug          # Android APK
./gradlew :desktopApp:run           # desktop, from the host
./gradlew testDevDebugUnitTest      # unit tests

The iOS app is built from ios/ in Xcode, not Gradle:

cd ios
open ZMyusic.xcworkspace
Windows says “Windows protected your PC”? The installer isn't signed with a paid certificate yet. Choose More info, then Run anyway.
05 · FAQ

Questions people actually ask.

Is ZMyusic free?

Yes. ZMyusic is free and open source under the GPL-3.0 licence. There is no account to create and nothing to pay — if it earns a spot in your rotation, you can chip in on Saweria.

Is it safe? What does it connect to?

ZMyusic is built from source on GitHub, and every release is produced by public CI. It talks to YouTube Music with your own account, and to GitHub Releases for its own updates. It hosts no media.

Is it affiliated with YouTube or Google?

No. ZMyusic is an independent, community-built client. It is not affiliated with, endorsed by, or connected to Google, YouTube or YouTube Music.

Which platforms are supported?

Android 8.0+ phones and tablets, Android TV, Wear OS 3+, Windows 10/11, Linux, macOS 13+, and iPhone/iPad on iOS 17+. The desktop build covers the same player, queue and lyrics as the phone.

Do I need a Google account?

No. You can use ZMyusic signed out for a clean, account-free player. Signing in with Google unlocks your personalised home, library and playlists.

How do updates work?

The app checks GitHub Releases on launch and when it returns to the foreground. When a newer build exists it offers it in-app — Android downloads and installs the APK straight over the old one.

Does it work with Spotify and my local files?

Yes. You can connect a Spotify account to play your playlists and Liked Songs, and ZMyusic scans your device's local music library alongside its streaming sources.

Can I scrobble?

Yes — ZMyusic scrobbles to Last.fm and ListenBrainz, and shows Discord Rich Presence with the live track and progress.

How do I uninstall it?

Uninstall it like any other app: on Android from Settings → Apps, on Windows from Apps & features, on macOS by moving it from Applications to the Bin, and on Linux with your package manager or by deleting the AppImage.
